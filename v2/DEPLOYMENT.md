# استقرار BAT-PANEL V2

## وضعیت این نسخه

این نسخه یک **Control Plane MVP** است: داشبورد فارسی متصل به API، ورود مدیر، ثبت رکورد مشتری و سرور، و منوی مدیریت ترمینال را فراهم می‌کند. این نسخه هنوز کانفیگ واقعی VPN نمی‌سازد و روی OpenVPN، Xray یا WireGuard تغییری اعمال نمی‌کند. شمارش ترافیک، اعمال خودکار حجم/انقضا، Agent اجرایی، ربات تلگرام و مهاجرت V1 نیز پیاده‌سازی نشده‌اند.

بنابراین این نسخه را پنل فروش عملیاتی VPN یا جایگزین V1 در نظر نگیرید. پروتکل‌های نمایش‌داده‌شده فعلاً فقط برچسب رکوردهای مدیریتی هستند.

## پیش‌نیاز

- Ubuntu 22.04 یا 24.04، معماری amd64
- دسترسی root و اینترنت
- Docker Engine و Docker Compose plugin
- حداقل 1 GB RAM برای آزمایش سبک؛ برای بار عملیاتی منابع بیشتری لازم است

## نصب

پس از انتشار نسخه روی شاخه اصلی:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/batvin/batpanel/main/install-v2.sh)
```

نصب تازه نام کاربری، رمز عبور حداقل ۱۴ کاراکتری و پورت محلی را می‌پرسد. فایل تنظیمات محرمانه در `/opt/batman-v2/.env` و اطلاعات ورود در `/root/batman-v2-credentials.txt` با مجوز محدود ذخیره می‌شود.

## دسترسی امن به داشبورد

پنل عمداً فقط روی `127.0.0.1` منتشر می‌شود و از اینترنت عمومی قابل دسترسی مستقیم نیست. از کامپیوتر خود یک تونل SSH بسازید:

```bash
ssh -L 8000:127.0.0.1:8000 root@SERVER_IP
```

اگر هنگام نصب پورت دیگری انتخاب کردید، عدد اول و مقصد بعد از `127.0.0.1:` را با همان پورت عوض کنید. تا وقتی نشست SSH باز است، در مرورگر خود باز کنید:

```
http://127.0.0.1:8000
```

برای دسترسی دائمی از دامنه، یک reverse proxy مانند Nginx یا Caddy با HTTPS و محدودیت دسترسی تنظیم کنید؛ پورت Docker را مستقیماً روی اینترنت باز نکنید.

## منوی مدیریت

با root:

```bash
bat-panel
```

امکانات:
- مشاهده وضعیت و سلامت
- restart، stop و start
- مشاهده لاگ‌ها
- پشتیبان‌گیری دیتابیس
- به‌روزرسانی از GitHub main
- تغییر پورت محلی پنل
- تغییر نام کاربری و رمز مدیر

## بررسی سرویس

```bash
docker compose -p batman-v2 -f /opt/batman-v2/docker-compose.yml --env-file /opt/batman-v2/.env ps
curl -fsS http://127.0.0.1:8000/api/health
```

## مسیرهای مهم

- تنظیمات محرمانه: `/opt/batman-v2/.env`
- اطلاعات ورود: `/root/batman-v2-credentials.txt`
- پشتیبان دیتابیس: `/var/backups/batman-v2`
- منوی ترمینال: `/usr/local/bin/bat-panel`

## حفظ نسخه قدیمی

نصب‌کننده V2 سرویس‌های نسخه قدیمی یا سرویس‌های VPN را متوقف یا حذف نمی‌کند. پیش از هر مهاجرت، از دیتابیس، گواهی‌ها و فایل‌های VPN بکاپ مستقل بگیرید و مسیر بازگشت را آزمایش کنید.
