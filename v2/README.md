# BAT-PANEL V2

نسخه دوم BAT-PANEL با داشبورد فارسی و API مرکزی. این شاخه در حال آماده‌سازی برای مدیریت عملیاتی Xray و OpenVPN است.

## وضعیت واقعی قابلیت‌ها

| قابلیت | وضعیت |
|---|---|
| داشبورد فارسی RTL + Glassmorphism و موشن | پیاده‌سازی شده |
| ثبت رکورد مشتری و سرور | پیاده‌سازی شده |
| **ساخت واقعی کانفیگ VLESS** (لینک + inbound JSON) | پیاده‌سازی شده |
| **ساخت واقعی کانفیگ VMess و Trojan** | پیاده‌سازی شده |
| **ساخت واقعی قالب OpenVPN** | پیاده‌سازی شده (گواهی روی نود) |
| **ساخت واقعی کانفیگ WireGuard** | پیاده‌سازی شده |
| **کنترل حجم و انقضا (auto-disable)** | پیاده‌سازی شده |
| قطع سرویس مشتری منقضی‌شده در پنل | پیاده‌سازی شده |
| منوی `bat-panel`، restart/start/stop/logs | پیاده‌سازی شده |
| بکاپ دیتابیس | پیاده‌سازی شده |
| Agent heartbeat + گزارش ترافیک | پیاده‌سازی شده (API) |
| اجرای واقعی Agent روی نود (اعمال کانفیگ روی Xray/WG/OVPN) | در حال توسعه |
| ربات تلگرام و نمایندگی | هنوز پیاده‌سازی نشده |
| مهاجرت کاربران V1 | هنوز پیاده‌سازی نشده |

**وضعیت فعلی:** این شاخه هنوز هسته‌ها و Agent اجرایی را نصب نمی‌کند. تا تکمیل نسخه نهایی و تست موتور، آن را روی سرور اصلی نصب نکنید.

## نصب

از ریشه مخزن با root:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/batvin/batpanel/main/install-v2.sh)
```

نصب‌کننده Ubuntu 22.04/24.04 و amd64 را هدف می‌گیرد.

## دسترسی امن

```bash
ssh -L 8000:127.0.0.1:8000 root@SERVER_IP
```

سپس `http://127.0.0.1:8000` را باز کنید.

## مدیریت

```bash
bat-panel
```

## مسیرها

- `install-v2.sh` — نصب و به‌روزرسانی
- `v2/backend` — API و تولید کانفیگ
- `v2/web` — داشبورد Glassmorphism
- `v2/scripts/bat-panel` — منوی CLI
- `v2/docker-compose.yml` — استقرار Docker
