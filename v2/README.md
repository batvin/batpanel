# BAT-PANEL V2

این پوشه شامل نسخه دوم BAT-PANEL است. V2 از داشبورد فارسی متصل به API، مدیریت رکوردهای مشتری/سرور، احراز هویت مدیر و منوی ترمینال برخوردار است.

## وضعیت واقعی قابلیت‌ها

| قابلیت | وضعیت |
|---|---|
| داشبورد فارسی RTL و ورود مدیر | پیاده‌سازی شده |
| ثبت رکورد مشتری و سرور در دیتابیس پنل | پیاده‌سازی شده |
| منوی `bat-panel`، restart/start/stop/logs | پیاده‌سازی شده |
| بکاپ دیتابیس پیش از update و تغییرات | پیاده‌سازی شده |
| نصب با پرسش نام کاربری، رمز و پورت | پیاده‌سازی شده |
| تغییر نام کاربری و رمز مدیر از منوی CLI | پیاده‌سازی شده |
| تغییر پورت و به‌روزرسانی از GitHub | پیاده‌سازی شده |
| provisioning واقعی OpenVPN/Xray/WireGuard | هنوز پیاده‌سازی نشده |
| شمارش ترافیک و اعمال حجم/انقضا روی VPN | هنوز پیاده‌سازی نشده |
| Agent اجرایی روی نودها | هنوز پیاده‌سازی نشده |
| ربات تلگرام و نمایندگی | هنوز پیاده‌سازی نشده |
| مهاجرت کاربران و داده‌های V1 | هنوز پیاده‌سازی نشده |

**مهم:** تا زمان تکمیل adapterهای VPN و تست روی VM مستقل، V2 جایگزین عملیاتی V1 نیست. سرویس‌های VPN قبلی را حذف یا متوقف نکنید.

## نصب

از ریشه مخزن با root:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/batvin/batpanel/main/install-v2.sh)
```

نصب‌کننده Ubuntu 22.04/24.04 و amd64 را هدف می‌گیرد و در نصب تازه نام کاربری، رمز عبور حداقل ۱۴ کاراکتری و پورت را می‌پرسد.

## مدیریت

```bash
bat-panel
```

منو شامل وضعیت، restart، stop، start، logs، backup، update، تغییر پورت و تغییر مشخصات مدیر است.

## مسیرها

- نصب: `install-v2.sh`
- backend: `v2/backend`
- رابط وب: `v2/web`
- منوی CLI: `v2/scripts/bat-panel`
- Docker Compose: `v2/docker-compose.yml`
- راهنمای استقرار: `v2/DEPLOYMENT.md`
