# BAT-PANEL — Batman VPN Control Panel

پنل مدیریتی BAT-PANEL با رابط فارسی و راست‌چین، مدیریت چند سرور و API مرکزی.

> **وضعیت نسخه 2:** نسخه فعلی یک Control Plane آزمایشی با داشبورد متصل به API است. ساخت/حذف/تعلیق واقعی کانفیگ‌های OpenVPN، Xray و WireGuard، شمارش ترافیک، Agent اجرایی، ربات تلگرام، نمایندگی و مهاجرت کاربران V1 هنوز تکمیل نشده‌اند. این نسخه را جایگزین عملیاتی پنل قدیمی روی سرور تولیدی نکنید.

## نصب BAT-PANEL V2

سیستم‌عامل هدف: Ubuntu 22.04 یا 24.04، معماری amd64، دسترسی root و اینترنت.

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/batvin/batpanel/main/install-v2.sh)
```

نصب‌کننده در نصب تازه این موارد را می‌پرسد:
- نام کاربری مدیر (۳ تا ۶۴ کاراکتر)
- رمز عبور مدیر (حداقل ۱۴ کاراکتر؛ حروف انگلیسی، عدد و علائم مجاز)
- پورت پنل (۱۰۲۴ تا ۶۵۵۳۵)

پس از نصب:
- آدرس محلی: `http://127.0.0.1:PORT` (با تونل SSH یا reverse proxy امن)
- مستندات API: `http://SERVER-IP:PORT/api/docs`
- اطلاعات ورود: `/root/batman-v2-credentials.txt` (دسترسی محدود root)
- دستور مدیریت ترمینال: `bat-panel`
- پشتیبانی: [@shocavpnadmin](https://t.me/shocavpnadmin)

پنل فقط روی `127.0.0.1` در دسترس است و مستقیماً روی اینترنت منتشر نمی‌شود. برای دسترسی از کامپیوتر خود از تونل SSH استفاده کنید: `ssh -L 8000:127.0.0.1:8000 root@SERVER_IP` و سپس `http://127.0.0.1:8000` را باز کنید. برای دسترسی دائمی، reverse proxy با HTTPS تنظیم کنید.

## منوی مدیریتی

با root اجرا کنید:

```bash
bat-panel
```

امکانات:
1. وضعیت و سلامت پنل
2. راه‌اندازی مجدد
3. توقف و روشن‌کردن
4. مشاهده لاگ‌ها
5. پشتیبان‌گیری دیتابیس
6. دریافت آخرین کد از شاخه main و به‌روزرسانی
7. تغییر پورت
8. تغییر نام کاربری و رمز مدیر

قبل از به‌روزرسانی یا تغییر تنظیمات حساس، از دیتابیس V2 نسخه پشتیبان گرفته می‌شود. پشتیبان‌ها در `/var/backups/batman-v2` قرار می‌گیرند.

## داده‌ها و سرویس‌های نسخه قدیمی

کد نصب نسخه قدیمی از شاخه اصلی حذف شده است. انتشار قدیمی `v1.0.0` در GitHub Releases برای دریافت نسخه‌های منتشرشده قبلی نگه داشته می‌شود. حذف کد از مخزن به معنی حذف خودکار نرم‌افزار یا داده‌های سرورهای نصب‌شده نیست.

## معماری و پوشه‌ها

- `install-v2.sh`: نصب و به‌روزرسانی V2
- `v2/backend`: API و backend
- `v2/web`: داشبورد وب فارسی
- `v2/scripts/bat-panel`: منوی مدیریتی ترمینال
- `v2/docker-compose.yml`: استقرار Docker
- `v2/DEPLOYMENT.md`: راهنمای استقرار و عیب‌یابی

## امنیت

- رمز عبور قوی و محرمانه انتخاب کنید.
- پورت پنل را فقط برای IPهای مورد اعتماد باز کنید.
- برای استفاده عمومی HTTPS را فعال کنید.
- فایل `.env` و فایل اطلاعات ورود را در اختیار دیگران نگذارید.
- پیش از هرگونه مهاجرت یا حذف نسخه قدیمی، از دیتابیس، گواهی‌ها و فایل‌های VPN بکاپ مستقل بگیرید.
